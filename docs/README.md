# Project documentation

This directory is the canonical home for project knowledge that is too detailed for `AGENTS.md`.

- [`agent-workflows/`](agent-workflows/README.md) defines the shared SPEC, PLAN, IMPLEMENT, and REVIEW workflows for all coding agents.
- [`features/`](features/README.md) contains approved, implementation-ready feature specifications.
- [`architecture.md`](architecture.md) documents the Rails structure and presentation surfaces.
- [`security.md`](security.md) documents security, ownership, file, email, and payment invariants.
- [`participation-and-print-materials.md`](participation-and-print-materials.md) documents annual participation, setup, payments, and print-material behavior.
- [`stripe-integration.md`](stripe-integration.md) documents the real-payment boundary and rollout.
- [`prozesse.md`](prozesse.md) records business-process context. Verify planned or historical statements against current code.
- [`product-order-payment-cms-plan.md`](product-order-payment-cms-plan.md) is a draft plan, not evidence of implemented behavior.

Update these files when a change introduces a lasting architectural, operational, security, or domain invariant. Temporary task notes do not belong here.
